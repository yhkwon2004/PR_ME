# 권용현 — PHYSICAL AI · 3D 인터랙티브 포트폴리오

드론 · 로봇 · 모빌리티 · AI를 하나의 3D 세계에 올리고, **스크롤 페이지가 아니라 한 편의 영화처럼**
장면이 이어지는 포트폴리오입니다. 카메라가 세트 사이를 크레인 숏으로 날아다니며 10개의 장면을 원테이크로 잇고,
엔딩 크레딧과 엔드 카드로 마무리합니다. 프로젝트 41개 · 수상 43건(대상 7)과 상장 원본, 함께한 기관 31곳을 담았습니다.

배포: https://kwon-physical-ai.vercel.app

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # 정적 빌드 → dist/
npm run preview   # 빌드 결과 미리보기
```

### 카드 덱과 분위기

- 장면마다 프로젝트 · 상장 · 기사 카드가 **커버플로 덱**으로 넘어갑니다. 휠 · ← →로 한 장씩 넘기고, 휴대폰에서는 카드가 손가락을 따라 움직이다 놓으면 가까운 카드에 붙습니다(빠르게 튕기면 한 장 더). 프로젝트 덱의 마지막 장은 아카이브로 이어지는 '전체 보기' 카드입니다.
- **보도 덱**은 신문에서 오려 낸 기사처럼 — 제호 · 날짜, 사진(가운데에 오면 색이 돌아옴), 굵은 제목, '직접 소개 / 관련 보도' — 누르면 기사 원문이 새 창으로 열립니다.
- 가운데 카드 아래 설명 줄에 분야 · 연도 · 수상 등급과 **함께한 기관 로고**가 붙습니다.
- 가운데 카드가 바뀌면 배경이 따라 바뀝니다: 카드 사진을 흐린 빛, 큰 연도 글자, 카드 색으로 물든 지평선 · 바닥 격자 · 역광 · 화면 그레이드. 데스크톱에서는 뒤로 프로젝트 사진이 세 줄로 천천히 흘러갑니다.
- 사운드는 Web Audio로 합성합니다 — 단조 없는 밝은 장조 화음(Cadd9 → G → Fmaj7 → C/E), 위 음역의 부드러운 삼각파 패드, 오르골 같은 아르페지오, FM 일렉트릭 피아노, 짧은 잔향. 카드를 넘길 때 화음에 맞는 음이 울립니다. 브라우저가 자동 진입의 소리를 막으면 한 번 누르라는 안내가 뜹니다(휴대폰에서는 윗줄에 작게).

## 프로젝트 상세 페이지

- **필름 장면**은 텍스트를 줄이고 실제 프로젝트 사진 카드(릴)로 구성했습니다. 카드를 누르면 상세 페이지가 열립니다.
- **`/works`** — 전체 프로젝트 아카이브(사진 중심 그리드, 분야 필터: Drone · Mobility · Robotics · AI · IoT/H·W · Product · Software).
- **`/works/<id>`** — 프로젝트 상세: 전면 사진 히어로 → 요약·역할·기간·도구·수상 → 함께한 기관(로고) → 상장 → 사진과 짝지은 스토리(문제 → 제작 → 검증 → 결과) → 갤러리(확대 보기) → 영상 → 이 프로젝트를 다룬 공식 보도 → 원문 링크 → 다음 프로젝트.
- 주소가 실제로 바뀌므로 링크 공유·새로고침·뒤로 가기가 동작합니다(Vercel `rewrites`).

- **`/awards`** — 수상 아카이브: 대표 상장(대상)을 먼저, 나머지 수상은 '모두 보기'로 펼침 · 등급 필터, 상장 원본 확대 보기, 상을 준 기관 로고와 이어진 프로젝트.
- **`/skills`** — 보유 스킬: 8개 분야 · 75개 기술. 숙련도 점수 대신 근거를 셉니다 — 기술마다 그 기술이 적힌 프로젝트(도구 · 역할 · 요약 · 스토리)와 그 프로젝트의 수상, 자격증 9개. 기술을 누르면 근거 프로젝트가 열리고, 아직 기록된 프로젝트가 없는 분야(휴머노이드 등)는 '탐구 중'으로 표시합니다.
- **기관 × 프로젝트** — `/works` · `/awards` 아래에 함께한 기관 31곳을 로고와 함께 보여 주고, 기관마다 이어진 프로젝트와 수상 수를 붙입니다.

### 콘텐츠 갱신

프로젝트 내용과 사진은 노션 포트폴리오와 [yhkwon2004/portfoli](https://github.com/yhkwon2004/portfoli) 기록에서 수집해 근거가 있는 내용만 남겼습니다.

| 파일 | 역할 |
|---|---|
| `src/data/projects.json` | 프로젝트 상세 데이터(제목, 한 줄 소개, 역할, 도구, 수상, 스토리, 이미지 캡션, 링크) |
| `src/data/awards.json` | 수상 기록 `{date, contest, grade, prize, issuer, project, certs[], photo, orgs[]}` — 상장 이미지를 직접 읽어 옮긴 것 |
| `src/data/skills.js` | 분야 · 기술 · 자격증 목록과 근거 찾기(프로젝트 기록에서 표현을 찾아 잇는다) |
| `src/data/press.json` | 공식 보도(매체 · 날짜 · 제목 · 요약 · 원문 링크 · 관련 프로젝트) — 사진은 `public/media/press/` |
| `src/data/orgs.js` | 기관 목록 · 로고, 상장 수여자 → 기관 대응(`awardOrgs`), 프로젝트 ↔ 기관 관계, 기관별 색인 |
| `src/content.js` | 장면 문구, 장면별 프로젝트 순서(덱), 크레딧 |
| `public/media/projects/<id>/` | 프로젝트 사진(WebP 원본 1600px + 썸네일 720px) |
| `public/media/awards/` | 상장 스캔(1132 · 720 · 480 · 240px). 학번 · 생년월일 같은 개인정보는 가린 뒤 올립니다 |
| `public/media/orgs/` | 기관 로고(흰색 단색, 높이 120px) |
| `scripts/harvest.py` | 노션 서명 URL·로컬 파일 → EXIF 회전 보정, 중복 제거, WebP 변환 |
| `scripts/contact_sheet.py` | 사진 검토용 밀착 인화지 생성 |
| `scripts/build-projects.mjs` | 수집 결과를 `projects.json`으로 정리하고 누락 파일 검사 |

**상장을 추가할 때:** 스캔을 `public/media/awards/award-YYYY-MM-DD.webp`(1132×1600)와 `.md` · `.thumb` · `.sm` 변형으로 넣고 `awards.json`에 한 줄을 더하면 수상 수, 연도별 막대, 상장 덱, 크레딧 집계, 기관 연결이 모두 따라 바뀝니다. 수여자가 새 기관이면 `orgs.js`의 `ORGS`와 `ISSUER`에 한 줄을 더합니다.

**기관 로고:** 원광대 · 전북대 · 전남대 · GIST · 캠틱 · 전북현대 · 자동차공학회 · 창조경제혁신센터 · COSS는 각 기관의 공식 파일, 앵커사업단은 portfoli의 원본 파일, HUSS · GICON · 한국연구재단 · 전북특별자치도 · 기빙플러스 · 국립군산대 · 정부 상징은 상장에 인쇄된 로고를 따 흰색 단색으로만 바꿨습니다(새로 그리지 않음). 원본도 인쇄본도 없는 곳은 이름을 활자로 표기합니다. 표기는 이력을 밝히는 것이며 후원이나 보증을 뜻하지 않습니다.

## 관람 안내

- **처음 방문**: 첫 장면 아래에 사용법 세 가지(스크롤 · 카드 클릭 · INDEX)를 한 번 보여 줍니다(휴대폰은 위쪽 알림으로).
- **다음 장면 버튼**: 오른쪽 아래에 다음 장면 이름과, 자동 재생이면 넘어가기까지 남은 시간을 고리로 보여 줍니다(휴대폰은 첫 장면에서만).
- **손으로 넘기면 자동 재생 멈춤**: 휠 · 스와이프 · 방향키 · 카드를 직접 넘기면 읽는 도중 장면이 넘어가지 않도록 자동 재생을 멈추고 알려 줍니다(AUTO · `P`로 다시).
- **첫 카드 덱**: 덱이 옆으로 살짝 밀렸다 돌아오고 넘기는 법을 알려 줍니다.
- **장면 주소**: 주소에 지금 장면이 남습니다(`/#robotics`) — 새로 고침 · 공유해도 그 장면으로 들어옵니다. 다시 방문하면 지난번 멈춘 장면에서 '이어 보기'를 권합니다.
- **INDEX**: 장면 목록 위에 아카이브(WORKS · AWARDS · SKILLS), 연락처(이메일 복사 포함), 키보드 단축키.
- **작품 · 수상 · 스킬 페이지**: 위 막대에 읽은 만큼 차는 진행선, 한참 내려가면 '맨 위로' 버튼.

## 조작

- **휠 · 스와이프 · ← →** 다음/이전 장면 — 패널 안에서 스크롤할 내용이 남아 있으면 스크롤이 먼저입니다.
- **AUTO** 영화처럼 자동 재생(기본값). 패널 위에 마우스를 올리면 잠시 멈춥니다. `P` 키로 전환.
- **INDEX** 장면 바로가기(`I`), **SOUND** 합성 앰비언트 사운드(`M`), `Home`/`End`.
- 3D 오브젝트에 마우스를 올리면 정보가 뜨고, **클릭하면 반응**합니다(드론 플립, 로봇 점프, 로봇팔 손 흔들기, 뉴럴 코어 활성화, 로버 비상등).
- 드래그로 카메라를 살짝 돌려볼 수 있습니다.

## 접근성 · 성능

- `prefers-reduced-motion`이면 크레인 이동 대신 암전 컷, 자동 재생 꺼짐.
- WebGL이 없으면 정적 배경 위에서 같은 장면 진행과 콘텐츠를 제공합니다.
- 프레임이 떨어지면 해상도 → 블룸 순으로 화질을 자동으로 낮춥니다.
- 휴대폰: 1.25배 해상도 · 1/3 블룸으로 그리고, 3D 위에서 매 프레임 다시 그려야 하는 효과(반투명 막 흐림 · 화면 합성 사진 · 흐르는 사진 줄 · 카드 속 흐림)를 뺍니다. 손가락이 덱 위에 있는 동안은 자동 재생이 멈춥니다.
- 키보드만으로 모든 장면 · 링크 · 라이트박스를 조작할 수 있습니다.

## 배포
