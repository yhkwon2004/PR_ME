# 권용현 — PHYSICAL AI · 3D 인터랙티브 포트폴리오

드론 · 로봇 · 모빌리티 · AI를 하나의 3D 세계에 올리고, **스크롤 페이지가 아니라 한 편의 영화처럼**
장면이 이어지는 포트폴리오입니다. 카메라가 세트 사이를 크레인 숏으로 날아다니며 10개의 장면을 원테이크로 잇고,
엔딩 크레딧과 엔드 카드로 마무리합니다. 흐름은 **스플래시 → 표지 → 간단한 소개 → 연도별 이력 → 분야별 프로젝트 → 보도 → 수상 기록 → 크레딧**이고,
프로젝트 39개 · 수상 43건(대상 7)과 상장 원본, 함께한 기관 31곳을 담았습니다.

배포: https://kwon-physical-ai.vercel.app

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # 정적 빌드 → dist/
npm run preview   # 빌드 결과 미리보기
```

### 카드 덱과 분위기

- 장면마다 프로젝트 · 상장 · 기사 카드가 **커버플로 덱**으로 넘어갑니다. 휠 · ← → · 버튼 · 끌기(마우스 · 손가락 · 트랙패드 가로 스크롤)로 넘기고, 프로젝트 덱의 마지막 장은 아카이브로 이어지는 '전체 보기' 카드입니다.
- **움직임**: 덱 전체가 하나의 위치(소수)로 움직이고, 임계 감쇠 스프링이 그 위치를 초점 카드로 데려갑니다. 그래서 여러 장을 건너뛰어도 자리 사이를 이어서 지나가고, 넘기는 도중에 또 넘겨도 끊기지 않으며, 손을 놓으면 그 속도 그대로 이어서 붙습니다(스프링이 목표를 지나쳐 되돌아오지 않을 만큼만). 등장 · 자동 재생 · 끌기 안내도 같은 길로 그려지고, 프레임이 들쭉날쭉해도 같은 빠르기로 움직입니다.
- **손가락을 따라 끌기**: 가운데 카드가 손가락 밑에 1:1로 붙어 다닙니다(한 장 거리를 원근으로 줄어드는 만큼 짧게 — 20 · 40 · 60px 끌면 카드도 21 · 40 · 60px). 끌기가 시작되는 순간(8px)부터 손가락과 같이 움직여 덜컥 따라붙지 않고, 움직이던 덱에 손가락이 닿으면 그 자리에서 붙잡아 연달아 튕겨 넘길 수 있습니다. 반을 넘기면 놓기 전에 번호 · 아래 설명 · 배경 · 음이 그 카드로 바뀌고(안드로이드는 짧은 진동), 놓을 때 속도는 마지막 0.1초의 움직임으로 재서 세게 튕기면 두 장까지 더 갑니다. 끝에서는 점점 덜 끌리는 고무줄. 손가락이 덱을 잡고 있는 동안 휴대폰은 3D 배경을 초당 30프레임으로 줄여 카드가 매 프레임 움직일 여유를 남깁니다.
- **보도 덱**은 신문에서 오려 낸 기사처럼 — 제호 · 날짜, 사진(가운데에 오면 색이 돌아옴), 굵은 제목, '직접 소개 / 관련 보도' — 누르면 기사 원문이 새 창으로 열립니다.
- 가운데 카드 아래 설명 줄에 분야 · 연도 · 수상 등급과 **함께한 기관 로고**가 붙습니다.
- 가운데 카드가 바뀌면 배경이 따라 바뀝니다: 카드 사진을 흐린 빛, 큰 연도 글자, 카드 색으로 물든 지평선 · 바닥 격자 · 역광 · 화면 그레이드. 데스크톱에서는 뒤로 프로젝트 사진이 세 줄로 천천히 흘러갑니다.
- 사운드는 Web Audio로 합성합니다 — 단조 없는 밝은 장조 화음(Cadd9 → G → Fadd9 → C6), A4~B5 위에서만 숨 쉬는 사인 · 삼각파 패드와 한 옥타브 위에서 일렁이는 반짝임, 경쾌하게 오르내리는 오르골 아르페지오(두 마디마다 맨 위 반짝), 장면이 바뀔 때 새 화음을 아래에서 위로 훑는 소리(오프라인 렌더로 잰 스펙트럼 중심 455Hz → 722Hz), FM 일렉트릭 피아노, 밝고 짧은 잔향, 장면이 바뀔 때 높은 대역을 스치는 바람 소리. 카드를 넘길 때 화음에 맞는 음이 울립니다. **저음은 쓰지 않습니다** — 베이스 드론을 없애고, 마스터 앞에서 180Hz 아래를 24dB/옥타브로 깎고, 잔향은 320Hz 아래를 걸러 보내며, 전자피아노는 변조파를 두 배 높이로 두어 0Hz 쪽 '쿵' 하는 배음이 생기지 않게 했습니다(오프라인 렌더로 잰 150Hz 아래 에너지 비율 68% → 0.4%). 브라우저가 자동 진입의 소리를 막으면 한 번 누르라는 안내가 뜹니다(휴대폰에서는 윗줄에 작게).

## 프로젝트 상세 페이지

- **필름 장면**은 텍스트를 줄이고 실제 프로젝트 사진 카드(릴)로 구성했습니다. 카드를 누르면 상세 페이지가 열립니다.
- **`/works`** — 전체 프로젝트 아카이브(사진 중심 그리드, 분야 필터: Drone · Mobility · Robotics · AI · IoT/H·W · Product · Software).
- **`/works/<id>`** — 프로젝트 상세: 전면 사진 히어로 → 요약·역할·기간·도구·수상 → 함께한 기관(로고) → 상장 → 사진과 짝지은 스토리(문제 → 제작 → 검증 → 결과) → 갤러리(확대 보기) → 영상 → 이 프로젝트를 다룬 공식 보도 → 원문 링크 → 다음 프로젝트.
- 주소가 실제로 바뀌므로 링크 공유·새로고침·뒤로 가기가 동작합니다(Vercel `rewrites`). 상세 페이지의 '이 프로젝트 링크 공유'는 휴대폰에서 기기의 공유 창(카카오톡 · 메시지 등)을, 그 밖에서는 주소 복사를 엽니다.
- **`/history`** — 연도별 이력: 연도와 항목은 본인이 정리한 이력 그대로(`src/data/history.js`). 항목마다 2026 Notion 포트폴리오의 본인 기록 한 줄과 이어진 프로젝트 · 상장(누르면 크게) · 기사를 붙이고, 연도 아래에는 그 해의 다른 프로젝트와 수상(등급별 수 → `/awards#y2025`)을 모읍니다. 근거 기록이 없는 항목(테이블컵 인턴쉽 · EXPO 우수사례 전시 · 모두의창업 1기)은 이름만 둡니다. 필름의 이력 장면 · 프로필 · 페이지 탭에서 들어가고, `/history#h-<항목>` · `#y<연도>` 주소로 그 자리에 바로 섭니다.
- **프로젝트 정리**: 드론과 모빌리티는 한 분야(드론 · 모빌리티), AirSim 딥러닝 자율주행과 CARLA 엔드투엔드 시뮬레이터는 한 프로젝트(`airsim-driving`, 예전 주소 `/works/carla-e2e`는 새 주소로)로 합쳤고, 노출하지 않을 기록은 `projects.json`에 `"hidden": true`(페달 블랙박스) — 아카이브 · 덱 · 수 · 링크 미리보기 · sitemap에서 모두 빠집니다.
- **`/about`** — 프로필: 필름 · 아카이브에 흩어진 기록을 한 장에 — 이름 · 역할 · 소개, 메일 보내기 · 이메일 복사 · **PDF로 저장** · 링크 공유, 숫자(프로젝트 · 수상 · 자격증 · 보도 · 활동 연도), 핵심 역량, 학력, 걸어온 길(연도별 이력 항목 · 그 해의 프로젝트 · 수상 수), 대표 프로젝트 8, 수상 43건 전체, 자격증, 언론 보도, 분야별 기술, 연락처. 모두 기존 기록(`content.js` 소개 장면 · `projects.json` · `awards.json` · `skills.js` · `press.json`)에서 옮깁니다. 인쇄하면(PDF로 저장) 흰 종이 위 A4 이력서 모양(3쪽)으로 바뀝니다. 목차 · 엔드 카드 · 페이지 탭에서 들어갑니다.
- **링크 미리보기**: 카카오톡 · 링크드인 · 슬랙 · X에 주소를 붙이면 주소마다 다른 카드가 뜹니다 — 프로젝트는 대표 사진 + 분야 · 연도 · 제목 · 한 줄 소개 · 수상, 프로필 · 아카이브는 숫자와 대표 사진. 빌드할 때 `vite.config.js`가 주소마다 제목 · 설명 · 이미지를 바꾼 HTML(`about.html`, `works/<id>.html` …)과 `sitemap.xml` · `robots.txt`를 쓰고, 이미지는 `scripts/og_cards.py`가 `public/og/`에 만듭니다(프로젝트 기록이 바뀌면 다시 실행). 검색용 인물 정보(JSON-LD), 홈 화면 아이콘 · `manifest.webmanifest`, 없는 주소용 `404.html`도 있습니다.

- **`/awards`** — 수상 아카이브: 수상 43건 **전체**를 연도별로(해마다 대상부터, 연도 옆에 등급별 수) · 등급 필터, 상장 원본 확대 보기(화면 순서대로 넘김), 상을 준 기관 로고와 이어진 프로젝트. 필름의 수상 장면은 대표 상장(대상)만.
- **`/skills`** — 보유 스킬: 8개 분야 · 75개 기술. 숙련도 점수 대신 근거를 셉니다 — 기술마다 그 기술이 적힌 프로젝트(도구 · 역할 · 요약 · 스토리)와 그 프로젝트의 수상, 자격증 9개. 기술을 누르면 근거 프로젝트가 열리고, 아직 기록된 프로젝트가 없는 분야(휴머노이드 등)는 '탐구 중'으로 표시합니다.
- **기관 × 프로젝트** — `/works` · `/awards` 아래에 함께한 기관 31곳을 로고와 함께 보여 주고, 기관마다 이어진 프로젝트와 수상 수를 붙입니다.

## 관람 안내

- **처음 방문**: 첫 장면 아래에 사용법 세 가지(스크롤 · 카드 클릭 · 목차)를 한 번 보여 줍니다(휴대폰은 알림으로).
- **다음 장면 버튼**: 오른쪽 아래에 다음 장면 이름과, 자동 재생이면 넘어가기까지 남은 시간을 고리로 보여 줍니다(휴대폰은 첫 장면에서만).
- **손으로 넘기면 자동 재생 멈춤**: 휠 · 스와이프 · 방향키 · 카드를 직접 넘기면 읽는 도중 장면이 넘어가지 않도록 자동 재생을 멈추고 알려 줍니다(자동 재생 버튼 · `P`로 다시).
- **알림 위치**: 데스크톱은 왼쪽 아래, 휴대폰은 제목을 가리지 않게 장면 막대 바로 위(엄지가 닿는 곳)에 뜨고, 아래 가는 줄이 남은 시간을 보여 줍니다. 옆이나 아래로 밀어 닫을 수 있습니다. 가로 휴대폰은 장면 막대 위에 작게.
- **끌기 안내**: 첫 카드 덱에서, 그리고 손으로 보는 중(자동 재생 꺼짐)에 한동안 입력이 없으면 반투명한 손끝이 카드를 옆으로 밀고 — 덱도 실제로 다음 카드 쪽으로 살짝 끌려갔다 돌아옵니다. 넘길 카드가 없으면 휴대폰은 화면 아래에서 위로 미는 손끝, 데스크톱은 다음 장면 버튼이 손짓합니다(세션당 4번까지, 볼 때마다 더 오래 기다림).
- **휴대폰은 위로 밀면 바로 다음 장면**: 덱에 카드가 남아 있어도 카드를 하나씩 넘기지 않고 다음 장면으로 갑니다(아래로 쓸어내리면 이전 장면 · 그 장면의 첫 카드부터). 카드는 옆으로 넘깁니다(덱이 손가락을 따라 움직이고 놓은 속도대로 붙음).
- **당겨 넘기기(휴대폰)**: 위아래로 끄는 만큼 다음 장면 이름이 담긴 표시의 고리가 차오르고, 화면이 손가락을 따라 끌려옵니다(처음엔 손가락만큼, 더 끌수록 덜 — 고무줄처럼, 덱 아래 줄은 그동안 흐리게). 46px만 끌어도 고리가 다 차며(청록 · 짧은 진동) 놓는 순간 넘어갑니다 — 천천히 끌어도 됩니다. 22px만 움직였어도 빠르게 튕기고 놓으면 넘어갑니다(움직이다 멈추고 떼면 그대로).
- **끌려온 자리에서 이어서 전환**: 끌어서 넘기면 끌려 올라가 있던 패널이 그 자리에서 이어 위로 빠지고(이전 장면이면 아래로), 다음 장면 패널을 평소보다 빨리 들입니다(카메라 이동 1.6~2.5초 · 손을 뗀 뒤 약 0.7~1초에 등장). 뒤로 돌아온 장면은 글이 위에서 내려옵니다.
- **글을 끝까지 스크롤한 뒤 이어서 밀기**: 소개처럼 스크롤되는 글 상자 위에서 밀면 먼저 글이 스크롤되고, 끝에 닿은 뒤에도 손을 떼지 않고 더 밀면(끝에서부터 64px) 그대로 다음 장면으로 넘어갑니다.
- **장면 주소**: 주소에 지금 장면이 남습니다(`/#robotics`) — 새로 고침 · 공유해도 그 장면으로 들어옵니다. 다시 방문하면 지난번 멈춘 장면에서 '이어 보기'를 권합니다.
- **한눈에 보이는 이름**: 장면 · 버튼 · 덱 막대 · 페이지 글자를 한국어로(장면은 시작 · 소개 · 드론 · 자율주행·차량 · 로봇 · AI · 창업·제품 · 언론 보도 · 수상 기록 · 엔딩·연락처). 휴대폰은 위 버튼 아이콘 아래에 짧은 이름(자동 · 소리 · 프로젝트 · 목차), 아래 장면 막대는 지금 장면 칸만 넓혀 이름을 보이고, 카드 덱에도 ← → 버튼을 둡니다.
- **다음 장면으로 넘어가는 안내**: 카드 넘기기 안내처럼 반투명하게 — 덱의 마지막 카드에 손으로 닿거나 덱이 없는 소개 장면에서 잠시 머물면(휴대폰은 덱 장면에서도 7초쯤, 손을 쉬고 있을 때), 반투명한 손끝이 아래에서 위로 밀어 올리고 그 손끝을 따라 화면 전체가 살짝 끌려 올라갔다 돌아오며, 아래 표시에 '아래로 넘기면 · 다음 장면 · 드론'이 비칩니다(장면마다 한 번, 손으로 무엇이든 하면 바로 멈춤 · 카드를 넘기는 중이면 손을 쉴 때까지 미룸). 한동안 손을 놓고 있을 때도 같은 안내(휴대폰은 장면 넘김 · 카드 넘김 안내를 번갈아). 프로젝트 페이지 끝에는 '이전 프로젝트 · 다음 프로젝트' 카드와 ← → 키 안내.
- **목차**: 장면 목록(한국어 이름 + 영문) 위에 모아 보기(프로젝트 · 수상 · 스킬), 연락처(이메일 복사 포함), 키보드 단축키.
- **작품 · 수상 · 스킬 페이지**: 위 막대에 읽은 만큼 차는 진행선, 한참 내려가면 '맨 위로' 버튼.

## 조작

- **휠 · 스와이프 · ← →** 다음/이전 장면 — 패널 안에서 스크롤할 내용이 남아 있으면 스크롤이 먼저입니다. 데스크톱 휠 · 키는 덱의 카드를 한 장씩 넘긴 뒤 다음 장면으로, 휴대폰은 위로 밀면 바로 다음 장면 · 옆으로 밀면 카드.
- **자동 재생** 영화처럼 자동 재생(기본값). 패널 위에 마우스를 올리면 잠시 멈춥니다. `P` 키로 전환.
- **목차** 장면 바로가기(`I`), **소리** 합성 앰비언트 사운드(`M`), **프로젝트** 아카이브, `Home`/`End`.
- 3D 오브젝트에 마우스를 올리면 정보가 뜨고, **클릭하면 반응**합니다(드론 플립, 로봇 점프, 로봇팔 손 흔들기, 뉴럴 코어 활성화, 로버 비상등).
- **마우스로 끌어 넘기기**: 화면(빈 곳 · 카드 위)을 잡고 위로 끌어 올리면 다음 카드 · 다음 장면(아래로 넘기기), 끌어내리면 이전 — 손가락처럼 끄는 만큼 아래 표시가 차오르고 화면이 따라 끌려오며, 64px 넘게 끌고 놓으면 넘어갑니다. 끌고 놓은 뒤에는 카드가 열리지 않습니다. 옆으로 끌면 덱의 카드를 넘기거나(덱 위) 카메라를 살짝 돌립니다.

## 접근성 · 성능

- `prefers-reduced-motion`이면 크레인 이동 대신 암전 컷, 자동 재생 꺼짐.
- WebGL이 없으면 정적 배경 위에서 같은 장면 진행과 콘텐츠를 제공합니다.
- 키보드만으로 모든 장면 · 링크 · 라이트박스를 조작할 수 있습니다.

### 저사양 최적화 — 성능 단계(`src/core/perf.js`)

기기를 보고 시작 단계를 정한 뒤, 실제로 그려지는 프레임을 1초마다 재서 단계를 바꿉니다.

| 단계 | 3D | 화면 효과 |
|---|---|---|
| 0 최고(데스크톱) | 해상도 1.75배 · MSAA 4 · 블룸 · 먼지 100% | 모두 |
| 1 높음 | 1.5배 · MSAA 2 · 블룸 0.8 | 모두 |
| 2 보통(휴대폰 기본) | 1.25배 · MSAA 2 · 블룸 0.6 · 먼지 60% | `q-lite`: 뒤 흐림(backdrop-filter) · 화면 합성 · 흐린 사진 · 흐르는 사진 줄 · 장면 전환 흐림 없음 |
| 3 낮음 | 1배 · 블룸 끔 · 먼지 35% | `q-low`: 카드 사진 필터 · 큰 색 그림자 · 표면 빛 · 사진 확대 없음 |
| 4 최소 | 0.8배 · 블룸 · 먼지 끔 · **3D만 초당 30프레임** | 위와 같음 |

- **시작 단계**: 휴대폰은 2, 데스크톱은 0에서 시작하고 — 4코어 · 4GB 이하, 보급형 GPU(내장 Intel HD/UHD, Mali-G5x 이하, Adreno 5xx 이하 등), 2코어 · 2GB 이하, 데이터 절약 모드, 4K급 화면이면 한 단계씩 내립니다. 소프트웨어 렌더러는 바로 4.
- **실시간 조정**: 2초 연속 45fps 아래면 한 단계 내리고, 8초 연속 57fps 이상이면 시작 단계까지 다시 올립니다(바꾼 직후 2초 · 처음 3초 · 탭 전환 끊김은 재지 않음, 20초 안에 다시 내려가면 더 올리지 않음).
- **늘 아끼는 것**: 카메라 시야 밖 세트(로봇 관절 · 센서 계산)는 0.25초에 한 번만 움직이고, 라이트박스 · 인덱스가 열리면 3D를 초당 20프레임으로 줄이며, 작품 페이지가 덮으면 3D를 멈춥니다. 덱은 바뀐 값만 한 프레임에 한 번 쓰고(멈추면 쉼), 물러난 카드의 어둠은 불투명도로만 바꿉니다(다시 칠하지 않음). 타임코드 · 진행 막대 · 커서도 값이 바뀔 때만 씁니다.
- 주소에 `?q=0`~`4`를 붙이면 그 단계로 고정하고, `?perf`를 붙이면 단계가 바뀔 때 콘솔에 남깁니다.
- 손가락이 덱 위에 있는 동안은 자동 재생이 멈춥니다.

## 배포

Vercel에서 Vite 프로젝트로 자동 인식됩니다(`vercel.json` 포함). 저장소를 연결하면 푸시마다 배포됩니다.
현재 배포: https://kwon-physical-ai.vercel.app (`/about`, `/history`, `/works`, `/awards`, `/skills`, `/works/<id>`는 빌드가 미리 쓴 같은 앱의 HTML을 `cleanUrls`로 확장자 없이 내어 주고, 그 밖의 `/works/…`는 `rewrites`로 SPA(`/`)에 연결 — `cleanUrls`에서는 `/index.html`이 아니라 `/`로 보내야 합니다). 배포 주소가 바뀌면 `SITE_URL` 환경 변수로 링크 미리보기 · sitemap의 절대 주소를 바꿉니다.
